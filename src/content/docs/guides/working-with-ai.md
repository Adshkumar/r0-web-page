# Working with AI in r0

r0 brings supported AI coding integrations into the same desktop workspace as your project files. Provider availability and setup requirements are release-specific.

Before using an integration, check the current [r0 README](https://github.com/Adshkumar/r0#readme) and the provider's own setup instructions. Review generated changes in your project before keeping them.
