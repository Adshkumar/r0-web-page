# Project overview

r0 is a desktop code editor built with Rust, Tauri, and React, with current desktop releases for Windows and Linux. Its project repository is the source of truth for supported platforms, features, setup, and release history.

- [Source code and README](https://github.com/Adshkumar/r0)
- [Latest releases](https://github.com/Adshkumar/r0/releases)
- [Issues and feature requests](https://github.com/Adshkumar/r0/issues)

This site does not publish independent performance benchmarks or claim functionality beyond what is documented by the project.
