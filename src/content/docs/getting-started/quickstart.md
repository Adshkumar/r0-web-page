# First steps with r0

1. Install r0 using the instructions for the latest release.
2. Open a project folder in the editor.
3. Browse and edit files in the project workspace.
4. Use the integrated terminal for project commands.
5. Explore the Git and AI tools available in your installed version.

The exact controls and integrations can vary by release. See the [project README](https://github.com/Adshkumar/r0#readme) for current details.
