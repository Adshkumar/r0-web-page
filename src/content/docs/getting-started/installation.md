# Installing r0

Use the latest release listed in the [r0 GitHub releases](https://github.com/Adshkumar/r0/releases). Choose a package provided for your operating system.

For current setup requirements and platform support, follow the instructions published with that release. The available packages and install steps can change between releases.

The command shown on the [r0 home page](/) is provided for Windows PowerShell. Confirm the script source before running a remote installer.
